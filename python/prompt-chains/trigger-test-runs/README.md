## Agent run

In this playground - 

1. We have an endpoint/API response that is an array of Images.
2. On Maxim, we have created an agent - that takes up one URL and does some analysis on the image. We will trigger that agent using Maxim python SDK.
3. At the end - we will get the test run report.


## How to set up this repo?

1. Clone this repo.
2. Add `.env` file. Check `.env.example` file for reference. Add Maxim API Key.
3. Run `uv sync`
